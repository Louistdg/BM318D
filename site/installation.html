Installer DIOPTRE

Quatre étapes, une seule fois. Compte environ trois minutes, plus le téléchargement de Python.

  1. Installer Python 3.14

    Téléchargez Python 3.14 depuis python.org et lancez l'installateur.

    Cochez « Add python.exe to PATH » sur la première fenêtre. Sans cette case, DIOPTRE ne peut pas démarrer.

  2. Télécharger DIOPTRE

    Un seul fichier, l'installateur Windows (2 Mo). Aucune décompression.

    ↓ Télécharger l'installateur

  3. Lancer l'installateur

    Double-cliquez sur DIOPTRE-Setup-2.5.4.exe. Windows peut afficher un avertissement « application non reconnue » : cliquez sur Informations complémentaires puis Exécuter quand même.

    L'installation se fait dans votre profil, sans mot de passe administrateur.

  4. Ouvrir DIOPTRE

    Un raccourci DIOPTRE est créé sur le Bureau et dans le menu Démarrer. Double-cliquez dessus : l'interface s'ouvre à l'adresse ci-dessous.

    http://127.0.0.1:31880/

    Si le navigateur reste vide, attendez quelques secondes puis rechargez la page.

Pour le chat avec l'assistant IA

  1. Installer Ollama

    Téléchargez Ollama depuis ollama.com. Il s'installe sans droits administrateur.

  2. Télécharger un modèle

    Ouvrez un terminal et lancez la commande suivante (environ 2 Go pour le modèle recommandé).

    ollama pull qwen2.5:3b

  3. Choisir le modèle dans l'application

    Dans l'onglet « Agent IA local », le sélecteur en haut de la page liste les modèles installés. Choisissez-en un : votre choix est mémorisé.

Questions courantes

Où sont mes données ?

Dans le dossier d'installation (%LOCALAPPDATA%\DIOPTRE), fichier dioptre.sqlite3, et dans workspaces/ pour les fichiers importés. Rien n'est envoyé sur Internet.

Comment arrêter l'application ?

Fermez la fenêtre noire ouverte au lancement, ou double-cliquez sur ARRETER-DIOPTRE.cmd dans le dossier d'installation. L'arrêt propre enregistre la base et ferme le serveur.

Où sont les sauvegardes ?

Dans le sous-dossier backups/, avec une archive ZIP des fichiers importés. Une sauvegarde automatique est faite toutes les heures.

Le chat répond « Ollama ne répond pas »

Le moteur local n'est pas lancé. Ouvrez l'application Ollama, ou lancez ollama serve dans un terminal, puis renvoyez le message.

Puis-je l'utiliser sur plusieurs ordinateurs ?

Oui, en copiant le dossier complet, base comprise. Chaque copie garde ses propres données ; il n'y a pas de synchronisation.
